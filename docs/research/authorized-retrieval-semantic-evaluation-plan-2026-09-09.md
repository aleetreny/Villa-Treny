# Authorized retrieval: predeclared semantic evaluation

Status: design only, no inference dispatched. The released retrieval capability has mechanical tests; its autonomous use and semantic benefit remain unproved. This plan does not schedule a monitor or alter production.

## Eligibility before inference

The [complete revision247 eligibility audit](retrieval-evaluation-eligibility-2026-09-09.json) finds seven retained drafts, all already supplied in full to their authors. All25 prepared P6 contexts report zero omitted drafts. None is a valid real example of the access gap. Do not manufacture an omission, add a second document, remove visible text, or describe a currently visible document as recovered.

Select the first later available complete real cut containing a retained document that is authorized for a resident, omitted by that resident's P6 preparation, and explicitly relevant to an existing project or conversation. Freeze the source, state, exact ID/hash and the preexisting relevance evidence before dispatch. If several qualify, choose the oldest document, then its ID. If none qualifies, record **not evaluable**. Selecting such a future cut requires a separate read; this plan makes no promise to watch for it.

## Bounded comparison

Use the released P6 and P7 preparations of independent clones of the same initial state with the same model, seed, sampling limits and output cap. Allow at most three decision opportunities per variant, six inference requests total, with no retries outside that count. Use ordinary issued context and schema, without telling the resident to search, supplying a target response or fabricating an interlocutor. Freeze the per-opportunity procedure and complete budget before dispatch. Apply each response only through the real versioned domain path. No live world write, physical watch or provider quota reset is part of the evaluation.

This compares isolated choice and access, not production scheduling latency, twenty-five residents' autonomy or spontaneous relevance discovery across the whole world. The cases are selected for a real access need, so their outcome cannot be generalized into a population success rate.

## Separate access from understanding

**Access** requires the resident to choose the private search/read operations, select the exact retained revision and receive its original full bytes in a subsequent preparation. Record every operation, call and complete usage estimate up to delivery. A sentence claiming to have read the document is insufficient. If all three opportunities are needed to search, read and then use the text, do not silently add a fourth.

**Understanding** is judged separately. Before inference, retain two checkable document statements and a relevant distinction between an author's claim and a recorded physical/economic fact. Classify each as recognized, contradicted or not addressed. Check whether public speech, private explanation and the applied operation agree. Exact text delivery without faithful use is access achieved, understanding not demonstrated.

No lookup, choosing a different revision, exhausting the fixed opportunities, invalid output and invented document contents remain visible outcomes. A reasoned refusal is legitimate agency but is not successful retrieval. Sharing, publication, agreement acceptance and payment count only through their actual persisted effects; none is required for retrieval success. Preserve both raw outputs and all failed attempts privately, with only non-sensitive proof metadata in Git.

## Why these distinctions matter

The [earlier evidence-layout comparison](evidence-layout-semantic-review-2026-09-08.md) showed that better wording about access could coexist with false descriptions of authored content, and a single response could use a receipt correctly in private while contradicting it publicly. More schema-valid replies, drafts or offers do not by themselves establish useful social behavior. This plan tests the narrower causal claim enabled by [authorized retrieval](authorized-retrieval-implementation-2026-09-09.md); it does not repair or reinterpret those earlier negative results.
