# Decision-first protocol and truthful outcomes

This is a continuation of the preserved P4 release, not a claim that society quality is complete. The original limit of one model decision per physical watch has already been replaced by independent resident cognition and a shared, paced provider budget. This change addresses a different defect: accepting in prose while emitting another economic proposal.

## Changes under verification

Protocol5 emits an ordered two-element array: economic decision first, then the message/project/reflection/appraisal content. `no_deal` preserves ordinary discussion. Proposals retain freely chosen amounts, roles, deadlines and all existing work capabilities; acceptance names an actual incoming offer. Complete schema validation precedes a pure conversion to the established P4 authority. Saved protocols1–4 retain their original interpretation. No world schema, SQL migration, quota, clock or historical record changes are part of this release.

The Lives notebook shows recorded outcomes linked by conversation ID, offer ID and agreement ID. Speech alone cannot establish a transfer, work performance or payment. The Journal derives speaker metadata from the actual archived job/turn identifier without rewriting the stored row. Older API entries remain compatible. An independent review found no material provenance/privacy defect; a limitation remains that older entries without the matching provenance are not newly attributed.
