# Optional deal field order: six matched local samples

**Reordering `deal` before `message` changed none of the three outputs.** Both variants applied in all three cases, omitted deals and omitted `message.close`. Within each pair the original assistant content was byte-identical. This small test does not support changing property order alone as a remedy for suppressed proposals. It does not establish economic disinterest or exclude another effect of conditional branch selection or the grammar compiler.

This is an assistant-authored semantic review, not an expert/human evaluation. No responses, original contexts or historic ledgers were edited. The [machine report](report.json) retains its original pending-human-review marker.

## Preselected comparison

The earlier V7 batch had eight outputs containing a deal without the required open message. The three cases were selected and their request hashes saved in [the offline plan](preselected-plan.json) before any new HTTP request:

- G, initial index6: the prior output hired repair while falsely claiming an inspection was complete.
- L, initial index11: a plausible offer to help Juno with real maintenance repair.
- B, reply index0/sequence25: the prior output offered growing while discussing medical criteria, an unrelated physical effect.

Each exact before-response world/mind state was reconstructed using the original V7 source bundle and all earlier saved responses. The same SYSTEM, USER, seed, temperature, model, 1,024 output cap and disabled thinking were used in both variants. A applies the current complete conditional deal grammar to that original dynamic schema. B changes only object insertion order: wherever `properties` contains both fields, `deal` is moved immediately before `message`, including the full deal branch. Arrays, conditions, required fields, values and definition contents are otherwise identical. Canonically sorted schemas are equal. Branch order itself is unchanged.

Order was fixed as G:A/B, L:B/A, B:A/B. This is a small partial counterbalance, not randomized experimentation. Cases were selected from known failures, so they cannot estimate the society-wide frequency of negotiating. No instruction demanded a deal, no `close` was filled in, and no counterpart acceptance was injected.

The three offline tests checked exact reconstruction, unchanged messages/sampling, language equivalence, legal open deals, illegal missing/true close, extra fields, invalid amounts, self recipients, invalid appraisals, pre-request reservation durability, raw-response durability, idempotence and zero-request replay. They and ESLint passed before inference. Schema ordering is not guaranteed to become generation ordering inside a provider; this experiment tested the actual resulting requests and outputs, not an instrumented internal compiler trace.

Each subjective trust change affected only the current actor's directed relationship and applied once. No new economic capacity or emergent cooperation was demonstrated.

A conditional grammar fixed the known invalid-deal output language. These six samples show that a property-order permutation alone does not restore proposals for the selected cases. Whether the model actually reasons about optional branches, whether the backend canonicalizes them, and whether other representations improve grounded negotiation remain untested. Further changes should address a concrete mechanism; this result does not justify claiming successful economic autonomy or weakening consent validation.
