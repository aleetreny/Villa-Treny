It is not a human or blinded evaluation, an inference experiment, or proof of sustained autonomy. No provider or production API was called during this review. Private purposes, explanations, reflections and undisclosed character knowledge are not reproduced here. Quoted speech below was already present in the explicit public conversation/event projection. A legal output is distinguished from a supported claim and from an executed action.

## Exact evidence recovered without inventing missing inputs

Terminal-job retention deliberately replaces full input prompts with SHA256 markers. The observation backup retains the original outputs, original output-contract schemas, prepared-turn metadata, evidence IDs and application timestamps. Its raw prompt text alone is therefore insufficient for a semantic audit.

Replaying the eleven saved outputs in sequence from the complete backup taken immediately after SQL7 migration reconstructed **all 33 original text inputs exactly**: eleven SYSTEM messages, eleven USER messages and eleven prepared prompts matched their retained hashes. The evidence-ID lists matched **11/11**. The final public society projection matched the saved production projection exactly. Both complete backups passed the recovery verifier.

The public [proof manifest](first-live-turns-proof.json) records each pair of expected/reconstructed hashes, original schema hashes, evidence checks and the final projection hash. It contains no prompt or private-output prose. The [reproduction script](../../../scripts/review-first-live-turns.mjs) accepts private backup paths as arguments and forbids HTTP. Full reconstructed inputs were saved only beside the private observation backup, outside this repository.

There is a deliberate provenance distinction: the current schema builder differs structurally from the saved original schemas on the five reply turns, while the six initial-turn schemas match. The reply changes involve the current shared `$defs`/`$ref` and `anyOf` representation. **All eleven original stored schemas independently accept their actual outputs.** The input hashes prove the exact text supplied; they do not establish that today's entire provider request or schema serialization is byte-identical to the deployed one. The current pure application functions also reproduce the preserved public outcome.

## E: the four-material claim is not supplied evidence

E's exact USER context contains `public.stock.materials = 21`. That part of the message is grounded.

The four-material figure appears in the supplied recipe table as the **yield of excavation**, not as an allocation to Workshops. The repair recipe instead consumes one material. The actor's supplied knowledge, retained history and empty conversation do not establish a four-material allocation. The fact that E has an allocation-related duty and L has a salvage-related duty makes the proposed topic relevant; it does not make an invented allocation true.

The existing economy holds materials in a shared stock. The message does not call an allocation operation, transfer a supported resource or persist an offer. Its proposed reassignment of two materials must therefore remain proposed speech. This diagnosis distinguishes the real stock total from the unsupported antecedent and from the desired change.

## Kes, Ulla and Noor: three different limitations

**K's backlog is an unsupported factual assertion.** The exact context supplies K's communications role, B's question and existing personal-history references. It supplies no count of pending workshop logs, no garden updates and no queue measurement. B's later request is valid conversational evidence that K said this, not evidence that the alleged backlog exists. The sequence demonstrates how a false premise can persist through otherwise coherent dialogue.

**U's reply is causal negotiation over unverified supplies.** U heard A's request and asks appropriate follow-up questions. The claim to have spare paper/ink is ungrounded. A's later answer adds proposed quantities and a date, but the conversation never produces supported inventory, acceptance of those exact terms or a debt. It would be incorrect to count this exchange as a successful economic loan.

**N's criteria are a promise, not an accomplished artifact.** N answers C's actual request and frames the work conditionally. Neither the response nor a resulting action contains the criteria themselves. The current physical tools do not create an arbitrary medical policy document; the public project description cannot substitute for that missing result. This is weaker than K's invented status report: N has not claimed that the document already exists.

## Interpretation and bounded next checks

There is real conversational continuity: quantities and timing are discussed by A/U; C's request receives N's own response; B/K follow each other's preceding messages. Those are stronger observations than merely receiving eleven well-formed JSON objects.

The sample simultaneously exposes unsupported state claims, replies with a nonexistent conversational prelude, propagation of another speaker's invention, and queued physical effects that do not implement the stated social/documentary purpose. The system's guards prevented prose from manufacturing transfers, consent or resources, but they did not guarantee truthful or useful language. Empty physical plans are reasonable for genuine discussion; a completed purpose must still require the corresponding evidence.

This review does not change instructions, models, plans, schemas or production state. A later review should check whether the next speakers correct unsupported premises, whether actual criteria or other requested information are produced, and whether any separately accepted supported offers lead to real fulfillment and payment. Those outcomes are absent from this snapshot and must not be inferred from promises.
