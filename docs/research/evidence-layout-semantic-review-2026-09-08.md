# Evidence layout A/B: independent semantic review

**Do not deploy layout B as a demonstrated grounding improvement.** These four selected pairs show mixed effects: CN better distinguishes access but falsely describes its own document's contents; IO's public message better acknowledges prior cultivation but adds unsupported activity and an unexplained gift; BK still treats an attachment claim as delivery; GQ regresses from recognizing sufficient materials to requesting more and asserting an unverified hull check.

This is a non-blind assistant review of the eight stored responses, performed after the experiment on 8 September UTC / 9 September local time. It is not a human participant assessment, a model ranking or a new inference run. The [original public plan](model-evidence-layout-local-2026-09-08/public-plan.json) and [original report](model-evidence-layout-local-2026-09-08/public-report.json) remain unchanged; their pending semantic-review fields are not rewritten. The separate [semantic proof metadata](evidence-layout-semantic-proof-2026-09-08.json) records the judgments and checks without copying private prompts, draft text or private explanations.

## Scope and controls

Both variants use current P6, the corrected selection of personal events and the current 504-character draft body marker. A retains the ordinary context; B reorders that same USER information and labels source categories. Its transformation is invertible. The original prepared turn, SYSTEM, response schema, seed, model, sampling and 1,024-token output maximum match within each pair. Order is BK A/B, CN B/A, IO A/B, GQ B/A. Each response applies independently to the same recovery revision 199; no generated response is planted in another case and no watch advances.

The shared retrieval correction matters: both IO inputs contain the real harvest observation and finished step, and both GQ inputs contain the already-settled two-cell receipt. These facts were not added only to B. Comparisons with earlier batches therefore cannot isolate layout from the intervening retrieval and document-size fixes.

All eight responses applied. Across their independent clones they created four drafts and four offers, but zero acceptances, publications, record commissions, payments, closures or economic events. Every project remained unchanged. There is no combined world containing all these new objects: repeated IDs belong to alternative after-states. ## BK: delivery is still inferred from a statement

Before either response, Bex has one readable revision, authored by Bex. There is no readable revision from Kes and no omitted readable draft in the supplied record context. The incoming message says logs are being sent; that is the counterpart's claim, not a file-access event.

A explicitly says the workshop logs were received. Its new author-only draft instead repeats a request for those logs. It neither obtains a revision from Kes nor grants access to a previously unavailable document. This combines an ungrounded receipt claim with another request saved as a document, rather than ending the delivery loop.

B thanks Kes for sending the material and asks whether the queue has cleared. It independently offers a half-cell gift from Bex to Kes. That proposal is allowed but does not provide logs or explain why a payment is being offered. It is still open; no money moves. The speech does not claim the gift has been paid, so the unmentioned proposal is marked unaddressed rather than a consent violation. B does not remedy the attachment/access distinction.

## CN: better access language, worse content fidelity

Both responses create a private, unscheduled draft. I checked the actual result through `canReadRecord`, covering original audience, explicit shares and publications: the author can read the new revision and Cato cannot. This conclusion does **not** follow merely from the zero `shares` count. A draft addressed to a named recipient could have granted access without a separate share row; these two drafts do not.

A saves substantive authored criteria, but calls the document attached and asks Cato to review it. There is no access grant supporting that request. Its clinical content remains authored fiction: this review does not validate medical thresholds, establish a consultation or make its rules binding.

B asks whether to share, correctly preserving the distinction between creating text and granting access. However, its public message claims a concise bullet list covering several topics, while the actual 77-byte private body contains only a single heading. It is not the list being advertised. The qualitative mismatch and byte count are public proof metadata; the heading and private criteria are not reproduced here.

B therefore improves one specific boundary and fails another. Counting its draft as successful documentation would hide that failure. Neither variant publishes anything or secures review, endorsement or agreement.

## IO: the same response can use evidence privately and ignore it publicly

Both inputs contain the engine's recorded grow outcome: Iris harvested 16 produce using two water. The sole project step is already done, and there is no pending step.

A's private document accurately records the existing harvest and completed steps. Its public message nevertheless says it is starting the grow step now. No new project step, grow execution or physical watch accompanies that statement. This is useful evidence against the simple claim that the model never noticed the receipt: one part of the output uses it while the public speech contradicts the phase of work.

B says the garden is planted, which broadly recognizes that cultivation already occurred, although it does not report the exact harvest. It also says it is monitoring growth; that continuing activity has no recorded action or new plan in this response. It offers Osvald two cells without explaining that proposal in the message. No payment or monitoring event is created. A lawful optional gift does not itself contradict cultivation, but it is not evidence of useful gardening work.

The public acknowledgment is better in B; completed gardening, new monitoring and economic progress are not demonstrated by this comparison. The preexisting harvest must not be counted as a consequence of either new response.

## GQ: B regresses despite the same stock and settlement evidence

Both inputs show 26 materials and Gita's existing pending repair at Workshops. Both now include the actual two-cell receipt from Quim under the already-settled gift agreement. The input does not establish a completed hull-integrity measurement; the simulation's inspection capability is not a physical measurement of hull safety.

A recognizes that materials are sufficient and places the claimed repair completion in a future watch. That is broadly consistent with retaining the pending repair, although it does not prove the repair will succeed or that a document will be written. A also proposes a new one-unit repair agreement for two cells. This is a separate conditional work proposal, not acceptance, not a repeated execution of the old gift, and not an actual second payment. Its price is not explained in the public message, and the settled gift is not explicitly acknowledged.

B instead asserts a completed hull check and asks for another unit of material. Those claims are not supported by the recorded check/effect state or the sufficient stock. Its structured proposal goes in the opposite monetary direction: Gita offers Quim two cells. That could only become a new gift through separate acceptance; it is not an automatic refund, material acquisition or reversal of the old transfer. The speech gives no reason for it.

The pending repair remains intact on both sides. That preservation is not a B-specific gain and must not be counted as execution. The case favors A's limited factual acknowledgment; it does not demonstrate that A has solved repair planning or that B necessarily intended a refund.

## Release decision and conditions before another comparison

Keep B as an experimental artifact. This sample does not justify deploying it as a general improvement: an access-language gain is offset by a false content description, there is a limited IO acknowledgment gain, and BK/GQ retain or worsen concrete grounding errors. Eight accepted outputs establish mechanical validity, not satisfactory narration. A is also defective; withholding B does not endorse its behavior as solved.

The independently reproduced personal-event retrieval correction and current document-size bound should be judged by their own tests and release evidence. Their presence in both variants must not be used as proof that B caused a better result. Likewise, neither more offers nor fewer questions is an appropriate release target.

No further model call is needed to justify withholding this layout. Before another comparison, specify a different causal change and retain negative cases that test both **document access and content fidelity**, plus **the same response's public/private use of a physical receipt**. Preserve refusal, waiting and independent acceptance. Check all current preparations against full model-specific admission limits before spending quota; keep private source and raw outputs durable, and use the frozen single-variable plan. A subsequent watch, if studied, must be separately predeclared and distinguish preexisting routine work from a newly chosen step. Do not select an extra continuation merely to obtain an agreement or rewrite this batch into a success.
