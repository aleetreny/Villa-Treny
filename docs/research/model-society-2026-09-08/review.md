# Real-core contract trial — rejected

8 September 2026. The isolated experiment used the actual scheduler, provider request builder, parser, society validator and physical engine.

- 25 attempted calls: the first received HTTP401 from an expired OAuth session. Its 55-neuron reservation remains conservatively charged. Authentication was refreshed with Wrangler; that ID was not retried.
- The other24 calls completed. None produced an accepted resident decision. The model tended to fill every optional top-level field, invent offer IDs/recipients and combine mutually exclusive offer/respond branches. Several strings were not valid JSON.
- Total accounting321 neurons, including the55 unknown reservation. Reported-complete responses account for266. No ranking or successful autonomy is claimed.
- The provider builder only described a shallow schema in prose and did not send response_format. The task instruction did not clearly ask for an initiative grounded in the resident's purpose. Both require a separately recorded comparison, not a relaxed validator.
- A physical watch ran on the fallback engine: no model-authored projects, conversations or agreements were committed; no economic effect was invented. Replanning was not attempted because every resident had just failed and the real scheduler applies its30-minute backoff.
- The raw responses, charges and application codes remain in ledger.json. The manifest hashes bind this historical run to its exact sources; subsequent corrections intentionally require a new experiment directory.

These findings block deployment until a corrected real-provider contract is verified.
