# Interface fonts

Self-hosted; no Google Fonts request is needed to open the observer.

- Pixelify Sans: existing project asset, with `PixelifySans-OFL.txt`.
- IBM Plex Sans Condensed: existing project assets, with `IBMPlexSansCondensed-OFL.txt`.
- IBM Plex Mono Regular: downloaded unchanged from the [official IBM Plex repository](https://github.com/IBM/plex/blob/master/packages/plex-mono/fonts/complete/ttf/IBMPlexMono-Regular.ttf) on 7 September 2026. Covered by the same IBM SIL Open Font License included here.
